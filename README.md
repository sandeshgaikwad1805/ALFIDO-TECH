# Iris Dataset Analysis and Classification

# Problem Statement

I want to examine the Iris flower dataset and build a machine learning model that can predict the species of an Iris flower using its sepal and petal measurements.

I see that the data set contains measurements such as length, sepal width, petal length and petal width for various Iris species.

# Objectives

- I will. Understand the Iris data set.

- I will check the Iris data set for missing values and duplicate records.

- I will perform exploratory data analysis on the Iris data set.

- I will visualize relationships between features of the Iris data set.

- I will build a machine learning classification model for Iris species.

- I will evaluate the performance of the Iris model using metrics.

# Dataset

The Iris data set contains the following features:

- Sepal Length

- Sepal Width

- Petal Length

- Petal Width

- Species

The target variable is `species`.

I see that this project shows how exploratory data analysis and machine learning can classify Iris species based on their measurements.
